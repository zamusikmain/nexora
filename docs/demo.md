# Демонстрация NEXORA на ноутбуке

## Запуск одной командой

```powershell
Copy-Item .env.example .env        # только при первом запуске
docker compose --profile demo up --build
```

Через 1–2 минуты откройте адрес из `WEB_ORIGIN` в `.env` (по умолчанию `http://localhost:3000`). Вводите адрес **точно так же**, как он записан в `WEB_ORIGIN`: `localhost` и `127.0.0.1` для системы разные.

Сервис `demo` один раз создаёт демо-компанию и завершается. Повторный запуск ничего не меняет.

**Сброс перед следующим показом.** `down -v` удаляет **всю** локальную базу и файлы этого compose-проекта, а не только демо. Если в этой же установке есть данные, которые нужно сохранить, держите демо в отдельной копии проекта или с другим именем: `docker compose -p nexora-demo --profile demo up --build`. Тогда и сброс делайте с тем же `-p nexora-demo`.

```powershell
docker compose --profile demo down -v
docker compose --profile demo up --build
```

## Сценарий на 10–15 минут

Удобно держать два окна браузера: обычное и инкогнито, чтобы быстро переключаться между сотрудниками.

1. **Айгерим — рабочий день бухгалтера.**
   - Обзор: документы по статусам и типам.
   - Документы: папки «Договоры 2026» и «Бухгалтерия», избранное, поиск по названию и номеру.
   - Уведомления: договор поставки согласован; допсоглашение вернули с комментарием юриста; письмо в ДГД отклонено; IT-договор просрочен.
2. **Версии и сравнение.** Откройте «Акт выполненных работ за октябрь 2026»: две версии, кнопка «Сравнить с текущей» показывает, что изменилась сумма. Старые версии неизменяемы, у каждой есть SHA-256.
3. **Новый договор и ЭЦП.**
   - Создайте документ типа «Договор» и загрузите файл.
   - У версии нажмите «Подписать ЭЦП»: откроется NCALayer, выберите ключ для подписи.
   - Запустите маршрут «Согласование договора».
4. **Данияр — юрист.**
   - «Мои согласования»: новые задачи и просроченная задача по IT-договору.
   - Согласуйте новый договор с комментарием: он уходит директору.
5. **Ерлан — директор.** Утвердите «Договор аренды офиса». Покажите, что Айгерим сразу получила уведомление «Документ согласован».
6. **Гульнара — контроль сроков.** Уведомление «Просрочено согласование в вашем подразделении»: видно, кто просрочил и какой был срок, но не само содержимое документа. Руководитель контролирует сроки, но не получает доступа к чужим документам.
7. **Безопасность.**
   - Под Асель попробуйте открыть ссылку на договор Айгерим: «Запись недоступна».
   - Конфиденциальные документы видят только участники процесса.
8. **Казахский язык.** Переключите язык вверху на «Қазақша»: интерфейс, статусы и уведомления на казахском.
9. **Администратор.** Журнал аудита: каждое действие (вход, загрузка, скачивание, решение, подпись) записано и не может быть изменено.

## Что честно сказать на показе

- **Проверка ЭЦП.** Подпись ЭЦП создаётся через NCALayer. Сервер проверяет её через NCANode; на демо-ноутбуке он не установлен, поэтому подпись помечена «сервер её не проверял». Проверку подключаем при внедрении.
- **Почта.** Уведомления на e-mail включаются настройкой SMTP; в демо они только внутри системы.
- **По требованиям заказчика при внедрении:** вход через AD/LDAP, просмотр PDF в браузере, полнотекстовый поиск.
