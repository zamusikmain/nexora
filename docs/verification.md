## Important policy limits
Workflow participants retain related document read access, including current/future edits and all versions; no revocation or version-limited ACL exists. Classification is metadata only. Legacy metadata PATCH without expected_revision is accepted for Iteration 1 compatibility, so optimistic concurrency is not mandatory for every client. Folder namespace is private; no company folder permissions. Physical purge deliberately remains absent to preserve immutable history. Scan attestations are immutable and do not expire/rescan; asynchronous scanning is pending. API upload scanning is synchronous with a bounded deadline. See security.md before any sensitive pilot data.

`.github/workflows/ci.yml` runs the same checks on every pull request and push to main: API ruff (app/tests/migrations/ops), mypy, `alembic upgrade head` + `alembic check`, pytest against a disposable PostgreSQL 17 `nexora_test` service, ops tests; web test/lint/typecheck/build and `npm audit --omit=dev --audit-level=high`; production API/web image builds, failing if the production API CMD migrates or seeds. Role-separation tests stay skipped in CI (they need the separate role cluster). An `e2e` job starts PostgreSQL, the API from source with a throwaway masked `DEMO_PASSWORD` seed and the built web app, then runs Playwright (Chromium): RU default and persisted language, rejected wrong password, sign-out redirect, create document → upload TXT v1 → exact-byte download, and another department's user receiving "Record unavailable" plus 404 on the file. Every E2E test fails on a browser CSP violation. Locally, against a running development stack whose `WEB_ORIGIN` equals the URL: `cd apps/web; $env:E2E_BASE_URL="http://127.0.0.1:3000"; $env:E2E_PASSWORD="<DEMO_PASSWORD>"; npx playwright install chromium; npx playwright test` (4 passed locally on 2026-11-08). The API job was rehearsed locally in a throwaway container (477 passed, 43 skipped; ops 11 passed, 1 skipped); the first real GitHub run is not yet observed.
