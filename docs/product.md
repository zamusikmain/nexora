# Product
NEXORA manages corporate document registration, metadata, private immutable file versions and accountable actions. Russian default and English UI. Iteration 1 builds the foundation; the product works without external AI or cloud services.
Roles: USER, REVIEWER, APPROVER, LEGAL, MANAGER, ADMIN. Departments and document types are database-backed. Workflow assignments will introduce participant access in Iteration 2.
Implemented scope is recorded in README and the final verification report. No legal compliance or production-readiness claims.
